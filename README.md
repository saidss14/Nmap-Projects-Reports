## Project Description

As part of my cybersecurity learning journey, I worked on this Nmap Network Scanning Project to gain hands-on experience with basic network reconnaissance and enumeration techniques. Instead of only learning the theory, I wanted to understand how cybersecurity professionals actually gather information about systems and networks.

In this project, I used Nmap to scan my local network, identify active devices, discover open ports, detect running services, and determine the operating system of a target machine. I performed different types of scans, analyzed the results, and learned how each scan provides valuable information about a network.

This project helped me better understand how networks communicate, how services are exposed through ports, and why reconnaissance is an important first step in cybersecurity assessments. It also improved my ability to interpret scan results and strengthened my practical knowledge of networking and cybersecurity concepts.

All scans were conducted in a controlled local environment for learning and educational purposes.
